documentation changelog, not an application release changelog (no

Initial creation of the full `product/` directory: vision, product
principles, requirements, feature catalog, personas, user roles,
permissions matrix, information architecture, user journeys, terminology,
roadmap, release plan, pricing hypotheses, success metrics, assumptions
and risks, and this changelog. Created alongside the corresponding
`docs/architecture/`, `design/`, `docs/project/phase-tracker.md`, and
architecture decision records. No product features were implemented in
this phase.
