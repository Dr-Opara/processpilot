# Mockups

No mockups exist yet as of Phase 0 (documentation-only phase — no UI is
built). This directory is a placeholder for design mockups produced
starting Phase 1.

When mockups are added:

- Use real or explicitly-marked-illustrative data only — never
  unmarked placeholder statistics, per
  [design/content-style.md — UI copy rules](../content-style.md).
- Reference the relevant [product/user-journeys.md](../../product/user-journeys.md)
  entry the mockup supports, where applicable.
- Prefer linking to the canonical source (e.g. a Figma file) over
  committing large binary exports to this repository where practical.
