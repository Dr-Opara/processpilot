# Icons

No approved ProcessPilot icon set has been supplied to the project as of
Phase 0. This directory is a placeholder.

When Phase 1 implements the component library, select a single,
consistent icon set (e.g. one open-source outline icon library) rather
than mixing icon styles/sources. Icons are functional (status, action,
navigation), not decorative illustration — see
[design/branding.md — what to avoid](../branding.md) (no generic robot
illustrations, no decorative glow/gradient treatments applied to icons).
