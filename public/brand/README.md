# ProcessPilot Brand Kit

Approved working brand assets derived from the original ProcessPilot logo and icon created for this project.

## Primary files

- `branding/processpilot-logo.png` — horizontal wordmark without tagline, transparent background
- `branding/processpilot-logo-with-tagline.png` — horizontal wordmark with tagline, transparent background
- `branding/processpilot-logo-dark.png` — dark-background wordmark
- `branding/processpilot-logo-with-tagline-dark.png` — dark-background wordmark with tagline
- `branding/processpilot-icon.png` — transparent orange icon

## Platform icons

The `icons/` folder includes favicon, Apple Touch, Android/PWA, and common raster sizes.

## Social media

- `social/processpilot-og-image.png` — 1200×630 Open Graph image
- `social/processpilot-social-dark.png` — 1200×600 dark social card

## Important limitation

The original approved artwork available here is raster artwork, not a true vector master. These files are production-ready for web implementation, but a professionally redrawn SVG master should eventually be commissioned for unlimited scaling and trademark-quality brand production.

Do not recolor, stretch, rotate, redraw, or substitute the approved mark.
