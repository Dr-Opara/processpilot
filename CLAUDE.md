# CLAUDE

This repository is being developed under the Phase 1 foundation plan for ProcessPilot.

## Rules

- Keep the implementation focused on the design-system and application shell foundation.
- Do not implement authentication, database access, billing, AI, workflow execution, or real customer data in this phase.
- Preserve existing working code and avoid unnecessary file movement.
- Use the existing package manager and lockfile conventions.
- Ensure scripts for dev, format, format:check, lint, typecheck, test, test:watch, test:e2e, and build exist and are functional.
